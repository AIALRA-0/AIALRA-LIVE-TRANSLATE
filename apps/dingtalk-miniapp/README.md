# DingTalk A1 前台能力探针

该目录验证两条相互独立的钉钉能力：A1 录音启动与设备状态查询，以及小程序 `RecorderManager` 前台音频帧上传

小程序页面进入后台后，录音持续性不满足长课程主链路要求

因此，这里的音频上传只用于前台短时验证

A1 设备仍优先承担高质量同步录音，并通过 `businessOrder` 绑定 AIALRA 会话；本地实时字幕在接口得到真机证据前由浏览器或 Android 客户端提供

- 第一步，在钉钉开发者工具中创建小程序并加入本目录编译后的逻辑

- 第二步，把 AIALRA 核心服务显式绑定到局域网地址，并把 WebSocket 地址加入小程序安全域名

- 第三步，先调用 `readA1Status` 保存设备状态，再用会话 ID 调用 `startA1Recording`

- 第四步，仅在小程序保持前台时启动 `ForegroundProbe`，核对服务端的 `audio.ack` 和音频块落盘记录

注：本目录不会保存企业应用密钥、访问令牌或设备序列号
