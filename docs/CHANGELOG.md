# 变更记录

## 1 2026-08-27 真实 GPU 混合链路

### 1.1 持久任务与恢复

- 新增 SQLite `model_jobs` 与 `worker_nodes`，支持优先级、租约、续租、重试、幂等键和重启恢复
- 音频窗口落盘后只创建 ASR 任务，ASR 完成后创建翻译任务，讲解与材料任务不阻塞实时字幕
- 停止录音时封存尾部音频，会话使用 `processing` 区分录音停止与模型完成
- GPU 离线时继续 ACK 和持久排队，不生成 mock、identity 或 deterministic 结果

### 1.2 私有 GPU Agent

- 新增私有 Worker Gateway、心跳、长轮询、任务下载、完成和失败接口
- 新增 Windows RTX GPU Agent，ASR 与 LLM 使用独立执行通道
- Worker 明文令牌使用 DPAPI 保存，服务器只保留 SHA-256 摘要
- Agent 支持退避重连、60 秒租约、20 秒续租和登录自启动
- VPS CPU Worker 与默认 Ollama 服务退出当前生产主路径

### 1.3 浏览器与视觉

- 麦克风采集改为 AudioWorklet，未确认音频写入 IndexedDB 并在恢复后重发
- 新增浏览器标签页与系统共享音频入口，并保留来源 ID
- 删除生产默认演示开关与 `/demo` 路由
- 页面改为黑白层级，红色只用于录音、停止、权限拒绝和错误
- GPU 状态、队列深度、处理位置和真实 Provider 进入同一课程页面

### 1.4 验证

- 本机真实 GPU：21／21 ACK，4 字幕，4 译文，1 材料页，1 讲解卡，14.201 秒
- 私有远程 GPU：21／21 ACK，4 字幕，4 译文，1 材料页，1 讲解卡，35.015 秒
- GPU 离线恢复：离线时 0 假字幕与 5 个排队任务，恢复后重复字幕为 0
- Core 重启恢复：任务与 `processing` 状态保留，恢复后重复字幕为 0
- 浏览器桌面、暗色与 390 px 窄屏通过，控制台错误与警告为 0

## 2 2026-08-26 浏览器与 VPS 展示入口

### 1.1 新增

- 浏览器正式收音增加 HTTPS 安全环境检查、麦克风设备选择和服务器 ACK 状态
- 健康接口公开部署模式、处理位置与 Worker 能力，界面不再把 VPS 错写为本机
- 新增 Core、Worker、CPU Ollama 的 Compose 部署包
- 新增 Nginx WebSocket/SSE、Authentik 共享网关和 Cloudflare 代理 DNS 自动化
- 新增中英文 README 和浏览器/VPS 上线方案

### 1.2 安全调整

- 移除网页远程字体请求，避免无关第三方资源访问
- 移除核心服务的宽泛跨域允许，生产浏览器保持同源请求
- 生产容器只映射回环端口，数据和模型目录与代码版本分离

### 1.3 验证

- Rust 10 项测试、格式检查和 `clippy -D warnings` 通过
- Python Ruff、mypy 和 6 项测试通过
- 网页 ESLint、TypeScript、4 项测试和生产构建通过
- Compose 配置解析和 Cloudflare DNS 工具语法检查通过

### 1.4 线上部署

- Cloudflare 代理 DNS、Let's Encrypt 证书、Nginx WebSocket 反向代理和共享 Authentik 应用已部署
- 三项容器只把核心端口映射到 VPS 回环地址，匿名请求和伪造身份头请求均返回登录跳转
- VPS 默认 ASR 从 `small` 调整为 `tiny + CPU int8`，并关闭 Hugging Face Xet 下载路径，避免首次模型下载阻塞展示验收
- 部署器增加 Linux 行尾约束、本机探针代理绕过和 Nginx 重载后的有限重试，两次失败部署均自动回滚
- 最终 VPS 合成端到端验收通过：13 个音频块全部确认，产生 3 条字幕、3 条译文、1 页材料和 1 张讲解卡
