### 1.2 分层模型与 GPU 遥测

- `faster-whisper small + CUDA float16` 处理实时 ASR，3B 处理翻译与滚动讲解，7B 只处理停止后的最终总结
- Qwen3-VL 8B 处理图片 OCR 与视觉解释，只在实时队列空闲时运行，并与其他大模型按需卸载
- 14B 最终总结超过 180 秒门禁，保留失败证据；7B 在 10 至 12 秒内完成同一证据约束任务，成为默认总结模型
- 最终总结从整场字幕、滚动总结和材料页均匀取样并保持时间顺序，不再只读取课程开头
- 修复 Core 最多发送 48 个滚动总结而 Worker 只接受 32 个的契约偏差，避免长课程在模型调用前被 `422` 拒绝
- GPU Agent 不再把 7B 总结期间 3B 暂时退出显存误判为 Worker 故障，31.479 秒真实总结探针期间 Agent 与 Worker 保持同一进程，small CUDA ASR p95 为 1.726 秒
- GPU Agent 每 5 秒上报利用率、显存、功耗、温度、当前模型、任务类型和队列深度，不上报主机名、设备序列号或进程列表
- small CUDA ASR 在 7B 讲解运行期间保持独立并发，真实并发探针的 ASR p95 为 602 毫秒
- 发布候选短测保留了 7B 滚动讲解导致翻译 p95 超标的失败证据，按冻结门禁退回 3B 后翻译 p95 从 10.272 秒降到 1.919 秒
- 后台总结完成前会卸载大模型并恢复 3B 常驻，下一次实时翻译不承担模型冷启动
- Windows 守护脚本现在主动启动并监控 Ollama；Ollama 连续 3 次失联时重启受控本地模型栈
- 安装器同时验证 3B、7B 和 Qwen3-VL 8B，缺少任一生产默认模型时停止安装

## 2 2026-08-29 长时恢复与线上安全

### 2.1 浏览器与私网恢复

- 新增 45 秒项目录音租约、10 秒续期、generation 接管和明确的冲突响应

- 修复重复课程音频被内容哈希误去重的问题，ASR 幂等键加入会话、来源和采集时间

## 4 2026-08-27 真实 GPU 混合链路
