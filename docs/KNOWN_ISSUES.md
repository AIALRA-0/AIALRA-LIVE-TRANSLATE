# 已知问题

## 1 外部条件

- A1 企业权限、访问令牌和真机未提供，DingTalk 真实请求尚未执行
- Android 调试 APK 已安装到 realme RMX5060、Android 15，型号和系统版本来自本轮真机设备记录；锁屏、耗电、来电、蓝牙和 Wi-Fi 切换尚未执行
- 真实课程许可、音频和目标用户尚未取得

## 2 实时处理

- 核心配置与自动化记录显示，静音分段使用 2 秒最短窗口与 8 秒最长窗口；阈值尚未根据真实课堂噪声、口音和长语句校准
- 翻译使用单段文本和有限上下文，合成样本中出现了不够自然的词语选择
- 核心服务配置文件设定周期讲解默认每 5 条字幕触发，尚未根据停顿、困惑或用户行为自适应
- ASR 已与翻译和周期讲解分离优先许可；翻译与讲解仍缺少独立有界队列和取消策略，长课程可能积压低优先任务
- 浏览器未确认音频目前保存在内存中；Android 已使用持久缓存；浏览器刷新恢复仍待实现
- Android 应用内停止已在本轮无声真机自检中完成核心会话和服务退出

- 通知栏停止复用相同的内部广播接收器，但尚未直接点击通知栏动作

## 3 多模态材料

- 图片会作为原图插入时间线，但默认解析器只返回尺寸元数据
- PDF、PPTX 和 DOCX 先提取文本；复杂布局、公式、图表和扫描件需要 Docling、OCR 或视觉语言模型
- 当前材料相关性使用最近页面，没有嵌入检索与时间锚点排序

## 4 产品交付

- 当前桌面入口是本地网页，Tauri 安装壳尚未实现
- 会话列表可由 API 读取，网页暂未提供历史会话选择与导出界面
- 原始音频保留期、删除、导出和备份界面尚未实现
- 局域网开发模式尚未加入设备配对和 TLS，默认保持只监听本机

## 5 浏览器与 VPS

- 浏览器断网时只在内存保存未确认块；刷新、崩溃或系统回收标签页会丢失这些尚未 ACK 的块
- 移动浏览器锁屏和后台录音受操作系统限制，长时移动收音仍优先使用 Android 前台服务
- VPS 只有 CPU，`small + int8` 和 1.5B 本地模型的真实延迟、队列增长与资源峰值尚未完成线上量化
- 当前是受保护的单用户展示结构；多用户会话所有权、配额和删除策略尚未实现
- Compose 首次构建和模型下载需要额外磁盘；上线后应清理本次构建缓存，但不能清理共享容器或其他项目数据
