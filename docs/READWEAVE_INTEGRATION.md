# ReadWeave 笔记接入

## 1 用途

ReadWeave 保存 AIALRA 课程事件的可读投影，适合继续整理、检索和补充个人笔记

AIALRA 的 SQLite 事件库仍是转写事实源；ReadWeave 离线、冲突或被重新部署时，不影响音频 ACK、字幕、译文和停止控制

## 2 数据范围

连接器默认写入：

- 稳定字幕：包含时间、原文、Provider 和 AIALRA 事件 ID
- 稳定译文：与对应字幕放在同一内容块
- 补充解释：按总结、补充背景、生僻词、疑似识别错误和复习问题分区，并保留字幕与课件证据 ID
- 材料索引：包含材料名称、页码、解析摘要、页面 ID 和相关讲解事件

连接器默认不写入原始音频、原始课件、临时下载地址、浏览器令牌和录音租约密钥

## 3 目录结构

```text
AIALRA 课程
└─ 项目名称
   └─ 课程会话名称
      ├─ 00 课程概览
      ├─ 01 实时转写与翻译
      ├─ 02 生僻词与补充解释
      ├─ 03 课件与证据索引
      └─ 99 我的笔记
```

`99 我的笔记` 只由用户编辑，AIALRA 不覆盖其正文

## 4 私有部署配置

Core 与 ReadWeave 应位于同一私有容器网络或只通过 VPS 回环端口通信

ReadWeave 页面使用与课程工作台相同的 Authentik 保护，公网 `/etapi` 和 `/etapi/` 固定返回 `404`，不能只依赖 ETAPI 自身的 `401`

脱敏代理模板位于 `deploy/nginx/readweave.conf.template`，真实域名、证书路径、私有上游和认证片段目录只在部署环境注入

部署 Secret 需要提供以下值：

```dotenv
# Core 只通过私有容器网络访问 ETAPI
AIALRA_READWEAVE_BASE_URL=http://readweave:8080
AIALRA_READWEAVE_ETAPI_TOKEN=replace-with-etapi-token
AIALRA_READWEAVE_ROOT_NOTE_ID=root

# 这个地址只用于用户主动进入笔记，示例使用保留域名
AIALRA_READWEAVE_PUBLIC_URL=https://notes.example.com
```

ETAPI Token 只保存在服务器环境文件或 Secret 管理器中；浏览器只接收连接器状态、预览内容和经过 Authentik 保护的笔记入口

## 5 同步与恢复

- 稳定字幕或译文完成后创建持久连接器任务
- 实时录音期间最多每 30 秒生成一个投影批次
- 停止录音后创建最终校对任务
- ReadWeave 离线时任务保留在 SQLite，恢复后按照幂等键补写
- 每次写入先创建 ETAPI revision，再读取远端内容并替换管理标记区
- 管理标记外的人工内容保持不变
- 管理标记缺失时停止覆盖，创建恢复副本并把项目状态标为冲突
- 用户修复管理标记并重新校对成功后，页面清除活动冲突状态，同时保留既有冲突事件作为审计记录

用户可以在同一课程页面查看 `等待同步`、`同步中`、`已同步` 和 `存在冲突` 状态，也可以主动触发一次全量校对

同页预览从 AIALRA 事件库读取每个最近会话的 3 组原文与译文，并显示讲解归档数量；接口仍受项目所有者校验，不读取远端人工笔记，也不需要把 ETAPI Token 发给浏览器

## 6 验证

验证需要覆盖以下结果：

- 相同项目和会话重复同步不会创建重复目录
- 人工写在管理标记外的内容在重新同步后保持不变
- 删除管理标记会产生恢复副本，原笔记不会被覆盖
- ReadWeave 停止期间课程模型链路继续完成，恢复后排队任务归零
- 生产日志和数据库配置状态中没有 ETAPI 明文令牌

完整实测结果见 [验证报告](VALIDATION_REPORT.md)
