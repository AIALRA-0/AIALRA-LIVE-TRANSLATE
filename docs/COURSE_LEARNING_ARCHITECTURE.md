## 发布门禁

先确认无活动录音与模型任务、数据库备份及可回滚镜像，完成身份代理和 Worker 私有通道复核，再按 `deploy/install_vps.sh` 的完整 SHA 发布。服务端显式设置 `AIALRA_LOCAL_ONLY=false`、`AIALRA_CLOUD_TEXT_ALLOWED=true` 后仅开放“可申请项目授权”的能力；实际课程仍须用户按项目选择。不得为了测试旧课而代替用户开启授权。发布后以合成课程完成租约、持久 ACK、稳定字幕、译文、材料入库、自动讲解、问答追问、整课总结和 ReadWeave 读回；任何一步失败就回滚。真实课程效果由用户上课时独立复核。
