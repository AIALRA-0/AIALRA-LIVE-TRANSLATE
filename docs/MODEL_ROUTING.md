# 模型分层与授权边界

状态日期：2026-08-31

## 1 当前决定

7B 负责连贯段落翻译和滚动讲解，14B 只负责停止后的最终总结，Qwen3-VL 8B 负责本地图片理解

这不是按参数量猜测，而是按 RTX 4080 上的真实延迟、显存、结构化结果和长时稳定性分工

云端增强默认关闭，没有独立应用凭据或逐项授权时，页面不得创建云端任务，也不得把本地失败改成云端占位结果

## 2 本地模型分层

| 任务 | 默认模型 | 当前证据 | 结论 |
|---|---|---|---|
| 实时 ASR | `faster-whisper small` CUDA float16 | 90 分钟正式长测 Provider p95 为 429 毫秒，端到端 p95 为 727 毫秒，无 OOM | 保持最高优先级，6 小时和 24 小时仍待完成 |
| 实时翻译 | `qwen2.5:7b-instruct` | 90 分钟正式长测 Provider p95 为 1341 毫秒，端到端 p95 为 1574 毫秒，无 OOM | 按连贯段落翻译，保留有限上文只解决术语和指代 |
| 滚动讲解 | `qwen2.5:7b-instruct` | 90 分钟正式长测 Provider p95 为 2781 毫秒，端到端 p95 为 2833 毫秒，无 OOM | 只在实时队列排空且形成大段落后运行 |
| 最终总结 | `qwen2.5:14b-instruct` | 90 分钟正式长测为 17049 毫秒，单次生成且无 OOM；历史轮次约 291 秒 | 停止录音且实时队列排空后运行一次，超过 120 秒进入可见失败和重试 |
| 图片理解 | `qwen3-vl:8b-instruct` | 冷启动 48.743 秒，热运行 12.906 秒 | 只在实时队列空闲时运行 |

旧提示词和过大的无结构输入曾让 14B 总结超过 180 秒；当前实现改为证据约束输入、有限重试和专用总结契约，最新 90 分钟正式轮次在 17.049 秒完成，但 6 小时和 24 小时仍需独立验证

## 3 为什么不再按声学碎片逐条翻译

ASR 的短窗口用于降低识别延迟，不等于可直接阅读的语言段落

V17 保留声学片段作为追加式证据，但先按终止标点、长度和片段数量整理成连贯段落，再创建一项 7B 翻译任务；网页和 ReadWeave 默认只呈现段落，内部片段仍可用于回溯

滚动讲解不再每五个片段触发，只有新增至少四个连贯段落、累计至少 900 字符且实时队列排空时才触发；一次模型结果在页面上呈现为一个教学块，内部再区分要点、背景、术语、疑似听写和复习问题

最终总结在录音停止且字幕、译文和材料任务排空后运行一次，因此可以使用 14B，而不占用实时翻译路径

图片 OCR、布局和视觉解释使用 Qwen3-VL 8B，普通文本模型不冒充视觉模型

## 4 云端高精度层

OpenAI 当前模型指南把 GPT-5.6 Sol 定位为复杂专业工作的旗舰模型，把 GPT-5.6 Terra 定位为智能与成本的平衡选择，两者都支持图片输入，Terra 支持 Responses API 和结构化输出

参考：[OpenAI 模型选择](https://developers.openai.com/api/docs/models)、[GPT-5.6 Terra](https://developers.openai.com/api/docs/models/gpt-5.6-terra)、[GPT-5.6 Sol](https://developers.openai.com/api/docs/models/gpt-5.6-sol)、[Responses API](https://developers.openai.com/api/reference/cli/resources/responses/methods/create)

冻结用途如下：

- Terra 只处理用户逐项选择的图片或文本，用于复杂课件和本地结果复核
- Sol 只用于用户主动触发的深度复核，不进入实时自动链路
- 原始音频不发送给云端模型
- 请求必须携带项目、会话、字幕或材料页标识和本次授权
- 发送前展示范围，服务端记录授权事件和实际 Provider
- 失败时保留本地结果和可重试状态，不生成假答案

## 5 当前云端状态

可选云端 Provider 必须为 AIALRA 提供独立应用凭据，不能复用、读取或推断其他应用的密钥

当前 AIALRA Core 没有已经验收的独立云端应用凭据

因此当前生产状态保持 `cloud_enabled=false`，本轮没有绕过密钥体系、读取其他应用凭据或伪造一次云端成功

启用条件是为 AIALRA 创建单独的最小权限密钥，完成合成图片和文本的真实调用、授权审计、失败重试与请求范围读回后，再开放逐项按钮

## 6 调度规则

1. ASR 始终高于翻译、讲解、总结和图片理解
2. 翻译使用独立领取通道，滚动讲解与翻译共用常驻 7B，避免频繁切换
3. 讲解、总结和图片理解单并发
4. 图片理解只在 ASR 和翻译队列为空时开始
5. 大模型按需卸载，多个大模型不无约束常驻显存
6. OOM 或 Provider 不可用时任务重新排队，不改成 identity、deterministic 或 mock 结果

## 7 需要继续验证的边界

- 7B 段落翻译与滚动讲解尚未覆盖足够多口音、中英混说、公式口述和专业术语
- Qwen3-VL 8B 尚未建立公式、图表、扫描件和复杂版式的公开基准
- 进行中的 VLM 请求不能被稳定抢占，新录音在此时开始可能出现一次冷启动延迟
- 云端高精度层尚未取得 AIALRA 专用凭据，因此仍是关闭状态
